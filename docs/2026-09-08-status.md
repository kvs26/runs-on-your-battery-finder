# Status snapshot — 2026-09-08

A point-in-time summary of what exists for `runsonyourbattery.com`. Not maintained going forward —
treat as a snapshot, not a living doc. For ongoing data-modeling decisions see
[region-and-platform-notes.md](./region-and-platform-notes.md); for the underlying design decisions see
`pipeline/power-tool-battery-compat/ideas/runs-on-your-battery-finder/prd.md`.

## Dataset (`src/data/catalog.json`)

- 38 battery platforms (e.g. DeWalt 20V MAX, Milwaukee M18/M12, Ryobi 18V ONE+, Makita 18V LXT, HART
  20V, Craftsman V20, plus many more slugs with 0 products so far).
- 21 gadget categories (fans, vacuums, inflators, lights, chainsaws, coffee-makers, speakers,
  power-inverters, mobility, sprayers, pressure-washers, water-pumps, cleaning, outdoor-lifestyle,
  inspection, food-drink, outdoor-power-equipment, specialty, coolers, wearables, + 1 more).
- 336 products total across all platform/category pairs.
- Only 7 platforms are confirmed to have real product data as of this snapshot: DeWalt 20V MAX,
  Milwaukee M18, Milwaukee M12, Ryobi 18V ONE+, Makita 18V LXT, HART 20V, Craftsman V20. The rest are
  scaffolded slugs awaiting data.
- Multi-region support (US/UK/DE/FR/IT/ES) is modeled per [region-and-platform-notes.md](./region-and-platform-notes.md);
  Ryobi US (TTI) vs UK/EU (Positec) are kept as separate platform slugs.

## Pages

- Home tool page (`src/pages/index.astro`) — list/grid results.
- Platform hub pages (`src/pages/[platform]/index.astro`) — one per platform, lists compatible
  categories with a thumbnail image per category.
- Platform × category detail pages (`src/pages/[platform]/[category].astro`).
- Calculator, methodology, FAQ, about, contact, privacy, disclosure, 404.
- Sitemap + robots.txt generated at build (`@astrojs/sitemap`).
- Current build: 216 static pages.

## Images

- One representative photo per category (20 files) at `public/images/categories/<slug>.jpg`, sourced
  from Pexels (free license, no attribution required), reused across every platform hub page.
- Downloaded at `w=640` for a lighter payload (~55KB avg, ~1.07MB total) — see build output size notes
  in git history / feature-notes/done.
- No platform/brand logos or images — intentionally skipped (trademark risk + user decision).
- Home page's per-product thumbnails are still placeholder text (`<div class="thumb">`), not photos —
  out of scope so far.

## Monetization / analytics

- Ads and affiliate links are both wired via `AdSlot.astro` / `AffiliateLink.astro` but **disabled**
  (`SITE.monetization.ads.enabled = false`, `SITE.monetization.affiliate.enabled = false` in
  `src/lib/site.config.mjs`).
- No analytics provider configured yet (`SITE.analytics`).
- Dark mode toggle is enabled; skin is `neutral`; layout mode is `list`.

## Known open items

- Most of the 38 platform slugs have no products yet.
- Home page product thumbnails still show placeholder text, not images.
- Vacuum category image was swapped once already for a better product shot (Pexels 12167650).
